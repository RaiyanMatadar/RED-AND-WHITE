# Introduction

**SQL**
S = Structured
Q = Query
L = Language

SQL is used to **CREATE, RETRIEVE, UPDATE, DELETE** from a database.
(This is commonly known as **CRUD** — Create, Read, Update, Delete)

There are **2 types** of databases:
**RELATIONAL** & **NON-RELATIONAL**

### Relational

It resembles an Excel spreadsheet kind of database.
Tables can form well-defined relationships with one another, which is done by **keys** (which we will cover later).

### Non-Relational

Also called **NoSQL databases**. Instead of tables, they store data in formats like documents (JSON), key-value pairs, graphs, or wide-columns. Examples include **MongoDB, Redis, Firebase, and Cassandra**. They are preferred when dealing with large-scale, unstructured, or rapidly changing data.

---

# Database Management System (DBMS)

A **DBMS** is software that allows you to create, manage, and interact with databases. Examples include **MySQL, PostgreSQL, SQLite, and Microsoft SQL Server**.

# Databases

**How to create a database**
```sql
CREATE DATABASE myDB;
```

**For deleting an entire database**
```sql
DROP DATABASE database_name;
```

**To use/select a database before working on it**
```sql
USE myDB;
```

# TABLES

**Creating a table with columns**
```sql
CREATE TABLE employees(
    employee_id INT,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    hourly_pay DECIMAL(5,2),
    hire_date DATE
);
```

**Renaming a table**
```sql
RENAME TABLE employees TO workers;
```

**Adding a column to an existing table**
```sql
ALTER TABLE employees
ADD phone_number VARCHAR(15);
```

**Changing a column name**

For **older MySQL/phpMyAdmin versions** (e.g., from XAMPP older builds), first run this to check current structure:
```sql
DESCRIBE employees;
```
Then use this older syntax:
```sql
ALTER TABLE employees CHANGE phone_number email VARCHAR(50);
```

For **newer MySQL versions (8.0+)**, this cleaner syntax works:
```sql
ALTER TABLE employees RENAME COLUMN phone_number TO email;
```
> Note: `RENAME COLUMN` was introduced in **MySQL 8.0**. It does not work in older phpMyAdmin/XAMPP versions that use MySQL 5.x.

**Modifying a column's data type or size**
```sql
ALTER TABLE employees
MODIFY COLUMN email VARCHAR(100);
```

**Moving the position of a column — after a specific column**
```sql
ALTER TABLE employees
MODIFY email VARCHAR(50)
AFTER last_name;
```

**Moving a column to the first position**
```sql
ALTER TABLE employees
MODIFY email VARCHAR(50)
FIRST;
```

**Deleting a column**
```sql
ALTER TABLE employees
DROP COLUMN email;
```
> ⚠️ Don't forget the semicolon at the end — your original was missing it.
