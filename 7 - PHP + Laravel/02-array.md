 Associative Arrays in PHP

 So far we’ve used arrays with indexs: 0, 1, 2…

You can also use arrays with named indexes as keys, and we call them associative arrays:

```php
$associativeArr = ['first' => 'a', 'second' => 'b'];

$associativeArr['first'] //'a'
$associativeArr['second'] //'b'
```
