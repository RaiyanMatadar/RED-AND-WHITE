```php
<?php

if ($_SERVER['REQUEST_METHOD'] == "POST"){

    // ❌ DON'T use htmlspecialchars() here when saving to database
    // htmlspecialchars() is ONLY for displaying data in HTML
    // If you use it here, it will store corrupted data like &lt; instead of <
    // Example: user enters "O'Brien" → stored as "O&#039;Brien" in DB ← WRONG
    $firstname = $_POST['firstname'];
    $lastname  = $_POST['lastname'];
    $pets      = $_POST['favorite-pet'];

    // ✅ For DATABASE protection, use Prepared Statements instead
    // Prepared statements prevent SQL Injection attacks
    // Example of SQL Injection: user enters " ' OR 1=1 -- " to break your query
    // Prepared statements handle this automatically and safely
    // Usage:
    // $stmt = $conn->prepare("INSERT INTO users (firstname, lastname, pet) VALUES (?, ?, ?)");
    // $stmt->bind_param("sss", $firstname, $lastname, $pets);
    // $stmt->execute();

    // Server-side empty check
    // Even though HTML has 'required', users can remove it via browser DevTools
    // So always validate on the server side as well
    if (empty($firstname)) {
        header("Location: 06-form.php");
        exit();
    }

    // ✅ Use htmlspecialchars() HERE when DISPLAYING data in the browser
    // This is where XSS attacks are neutralized
    // XSS Example: user enters <script>alert('hacked')</script>
    //   WITHOUT htmlspecialchars → browser EXECUTES the script  ← 💥 dangerous
    //   WITH htmlspecialchars    → browser DISPLAYS it as text   ← ✅ safe
    //
    // GOLDEN RULE:
    //   STORE  → raw data in DB (protected by prepared statements)
    //   DISPLAY → use htmlspecialchars() when outputting to browser
    echo "This is the data user submitted: \n";
    echo htmlspecialchars($firstname);
    echo htmlspecialchars($lastname);
    echo htmlspecialchars($pets);

    // Redirect after form submission
    // Prevents users from seeing the processing file directly
    // Also prevents duplicate form submissions on page refresh
    header("Location: 06-form.php");
    exit(); // ✅ Always call exit() after header() to stop further code execution

} else {

    // Blocks direct URL access to this file (e.g. someone visiting process.php directly)
    // Any non-POST request gets redirected back to the form
    header("Location: 06-form.php");
    exit(); // ✅ Always call exit() after header()
}
```

**Quick reference to stick in your head:**
```
$_POST data
    ↓
Save to DB   → Prepared Statements  (prevents SQL Injection)
    ↓
Display HTML → htmlspecialchars()   (prevents XSS)
```
