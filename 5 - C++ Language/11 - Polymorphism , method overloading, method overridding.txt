Polymorphism → "Many forms" → allows same function/operator 
to behave differently depending on context.


TYPES:
1. Compile Time → Function Overloading, Operator Overloading
2. Run Time     → Function Overriding (using virtual function)


<<< COMPILE TIME POLYMORPYSM >>>

This type of polymorphism is resolved at compile time, meaning the compiler 
determines which function or operator to call before the program executes.

1-Function Overloading:

- Same function name, different parameter list.
- Parameters differ by number or data type.
- Decided at compile time.
Example:
    void show(int a);
    void show(double a);
    void show(int a, int b);



2-Operator Overloading:

- Gives new meaning to existing operators for user-defined types.
Example:
    Complex operator+(Complex obj);


<<< RUN TIME POLYMORPYSM >>>

1-Function Overriding:
- Needs at least 2 classes (Base & Derived).
- Same function name + same parameters.
- Base function declared as virtual.
- Decided at run time using vtable.
Example:
    class Base {
      public:
        virtual void show() { cout << "Base\n"; }
    };

    class Derived : public Base {
      public:
        void show() { cout << "Derived\n"; }
    };


Virtual Table (vtable):
-------------------------------------------------------------
- Created when class has virtual functions.
- Stores addresses of virtual functions.
- Each object has hidden pointer (vptr) → points to vtable.
- Enables runtime polymorphism (dynamic binding).
