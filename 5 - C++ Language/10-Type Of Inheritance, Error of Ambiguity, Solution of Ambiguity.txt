what is an ambiguous error & its solution?
when we make an class with inheritance for for class A we make an member function as wheels and in class B we made an member function with the same name 
so in this scenario the compiler will get counfuse if we made an object and try to get the wheels function to then it will throw the error as ambiguous.
if  we want to use the specific class member function we can use the resolution operator eg. t1.car::wheels();
