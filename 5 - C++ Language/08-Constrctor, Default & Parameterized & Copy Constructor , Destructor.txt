What is an Constroctor?
A constructor in C++ is a special function inside a class that is automatically 
called when you create (or "construct") an object of that class.

🧠 Simple meaning:
When you make an object, the constructor runs automatically to set up the object 
properly before you use it.

Key takeaway: If you don’t create one, C++ gives you one automatically.But there is an condition 
as if there is no constructor defined then otherwise it wont create an auto Constroctor. such as 
className() { } this is an quick example of default Constroctor. 


Key takeaway: If you don’t create one, C++ gives you one automatically. But there is an condtion as

🧩 Key Points:
Name of constructor = same as class name.
No return type, not even void.
Called automatically when an object is created.
You can pass parameters to initialize values.
You can make multiple constructors (called constructor overloading).

How many types of Constructor?
1 - Default Constructor
2 - Paramemeterized Constructor 
3 - Copy Constructor

1 - Default Constructor.
Example
class Student {
public:
    string name;
    int age;

    // Default Constructor
    Student() {
        name = "Unknown";
        age = 0;
        cout << "Default Constructor called!" << endl;
    }

A constructor(Student) with no parameters — it sets up an object with default values.
Purpose: to give every new object some starting (default) values.

2 - Paramemeterized Constructor.
A constructor that takes arguments — used to initialize objects with different values.
Example
class Student {
public:
    string name;
    int age;

    // Parameterized Constructor
    Student(string n, int a) {
        name = n;
        age = a;
        cout << "Parameterized Constructor called!" << endl;
    }
