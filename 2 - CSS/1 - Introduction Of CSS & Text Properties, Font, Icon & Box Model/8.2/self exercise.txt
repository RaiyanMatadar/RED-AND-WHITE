🔤 Font Attachment (Offline)
What is the correct syntax to attach an offline font using @font-face in CSS?
@font-face {
    font-family: 'Mulish';
    src: url('Mulish-BlackItalic.woff2') format('woff2'),
        url('Mulish-BlackItalic.woff') format('woff');
	<!-- THIS IS AN woff type>
	
    src: url('Mulish-BlackItalic.woff2') format('woff2'),
        url('Mulish-BlackItalic.woff') format('woff');
	<!-- THIS IS AN ttf type>
	
    font-weight: 900;
    font-style: italic;
    font-display: swap;
}
Example: Using a .ttf or .woff file stored in a local fonts/ folder.
