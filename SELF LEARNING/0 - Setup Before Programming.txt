Creating a file in VS Code is not enough.
The file is just text. Your computer cannot run it directly.

Every language needs its own compiler or runtime installed.
Examples:

C++ → MinGW / GCC
Java → JDK
JavaScript (outside browser) → Node.js
Python → Python interpreter
C# → .NET SDK

You must add the language’s “bin” folder to the PATH in Environment Variables.
This allows the terminal to recognize commands like:
g++, java, node, python, etc.

Verify installation with version commands:

g++ --version
java --version
node --version
python --version

Only after installing and setting PATH can you run programs.
Examples:

C++ → g++ file.cpp -o file then ./file
Java → javac Main.java then java Main
Node.js → node script.js
Python → python app.py

VS Code does not run code by itself.
It only calls the compiler/interpreter you installed.
