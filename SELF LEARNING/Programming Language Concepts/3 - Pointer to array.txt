Pointer to Array

Concept:
A pointer to an entire array, not just the first element.

Example:

int main() {
    int arr[3] = {10, 20, 30};
    int (*p)[3] = &arr;  // pointer to array of 3 integers

    cout << (*p)[0] << " " << (*p)[1] << " " << (*p)[2];
}

👉 p stores address of the whole array
👉 To access elements, use (*p)[i]

Visualization:
arr → [10, 20, 30]
p   → &arr (entire array address)
