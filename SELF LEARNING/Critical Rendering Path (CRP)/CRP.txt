Critical Rendering Path (CRP) – Quick Note

Definition:
Steps the browser takes to convert HTML, CSS, and JavaScript into pixels on screen.

Goal:
Show content to the user as quickly as possible (reduce first render time).

Key Points:
1. HTML Parsing → Builds DOM.
2. CSS Parsing → Builds CSSOM (render-blocking).
3. JS Execution → Can block HTML parsing (unless defer/async is used).
4. DOM + CSSOM → Merge into Render Tree.
5. Layout & Paint → Page is drawn on screen.

Blocking Types:
- CSS: Full render-blocking (page waits for all CSS before first paint).
- JS: Parsing-blocking by default; can be made non-blocking with defer/async.

Why It Matters:
- Faster CRP = better performance, SEO, and user experience.
- Helps identify and remove render-blocking resources.
